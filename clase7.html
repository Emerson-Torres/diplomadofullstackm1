AuthService y JWT

El servicio que valida al usuario contra FakeStoreAPI, guarda la sesion local y permite controlar acceso a rutas protegidas.

Que es AuthService y como funciona el flujo

AuthService es la capa que concentra toda la logica de autenticacion. Asi evitamos repetir codigo de login en varios componentes y tenemos una unica fuente para: iniciar sesion, guardar datos del usuario, saber si hay sesion y cerrar sesion.

1
Usuario ingresa usuario y contrasena
2
GET a /users para validar que existe
3
Guardar currentUser y token en localStorage
4
El interceptor firma peticiones salientes
5
El guard bloquea rutas si no hay sesion
Logica del proyecto final: el login valida que el usuario exista en https://fakestoreapi.com/users. Si existe, se habilita la sesion y el alumno puede navegar a productos y carrito con persistencia por usuario.

Paso 2 auth.service.ts

src/app/services/auth.service.tsTypeScript
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { map, switchMap } from 'rxjs/operators';

@Injectable({ providedIn: 'root' })
export class AuthService {

  private usersUrl = 'https://fakestoreapi.com/users';
  private loginUrl  = 'https://fakestoreapi.com/auth/login';  // endpoint del token real

  constructor(private http: HttpClient) { }

  login(username: string, password: string): Observable<any> {
    // Paso 1: verificar que el usuario existe en /users
    return this.http.get<any[]>(this.usersUrl).pipe(
      switchMap((users) => {
        const user = users.find(u => u.username === username && u.password === password);
        if (!user) {
          throw new Error('Credenciales invalidas');
        }
        // Paso 2: si existe, obtener el token real desde /auth/login
        return this.http.post<any>(this.loginUrl, { username, password }).pipe(
          map((res) => {
            const session = { id: user.id, username: user.username };
            // Paso 3: guardar token real y datos del usuario en localStorage
            localStorage.setItem('currentUser', JSON.stringify(session));
            localStorage.setItem('token', res.token);
            return { token: res.token, user: session };
          })
        );
      })
    );
  }

  saveToken(token: string): void {
    localStorage.setItem('token', token);
  }

  getToken(): string | null {
    return localStorage.getItem('token');
  }

  isLoggedIn(): boolean {
    return !!this.getToken();  // true si hay token, false si no
  }

  logout(): void {
    localStorage.removeItem('token');
    localStorage.removeItem('currentUser');
  }
}
Nota Angular 20: los servicios no necesitan standalone: false. Ese decorador solo aplica a componentes. Un servicio con providedIn: 'root' funciona igual en Angular 20 que en versiones anteriores.

Interceptor HTTP

Es un middleware de HttpClient: intercepta cada request antes de salir, ideal para headers de autenticacion, logging y manejo transversal.

Que es un Interceptor HTTP

Un interceptor es codigo que Angular ejecuta automaticamente antes o despues de cada peticion HTTP. En esta clase lo usamos para adjuntar Authorization sin repetir ese header en cada componente.

sin vs con interceptor
// Sin interceptor — hay que agregar el token en cada llamada manualmente:
this.http.get('url', { headers: { Authorization: `Bearer ${token}` } });

// Con interceptor — el token se agrega automaticamente en TODAS las peticiones:
this.http.get('url');  // el interceptor lo intercepta y agrega el token antes de enviar

Paso 6 Crear el interceptor manualmente

El CLI no tiene un comando para generar interceptores con modulos tradicionales. Se crea el archivo manualmente en una nueva carpeta interceptors/ dentro de src/app/:

src/app/interceptors/auth.interceptor.ts — archivo nuevo creado manualmenteTypeScript
import { Injectable } from '@angular/core';
import { HttpInterceptor, HttpRequest, HttpHandler } from '@angular/common/http';

@Injectable()
export class AuthInterceptor implements HttpInterceptor {

  intercept(req: HttpRequest<any>, next: HttpHandler) {
    const token = localStorage.getItem('token');

    if (token) {
      // Clonar la peticion y agregarle el header de autenticacion
      const cloned = req.clone({
        setHeaders: { Authorization: `Bearer ${token}` }
      });
      return next.handle(cloned);
    }

    return next.handle(req);  // si no hay token, enviar sin modificar
  }
}

AuthGuard — Proteger rutas

Un guard es un portero de rutas: decide si Angular deja entrar al usuario a una pantalla antes de crear el componente.

Paso 7 Crear el guard manualmente

Que resuelve AuthGuard: evita que usuarios sin sesion accedan por URL directa a rutas privadas como /users.

Se crea manualmente en una nueva carpeta guards/ dentro de src/app/. El guard usa providedIn: 'root', por lo que no necesita registrarse en app-module.ts:

src/app/guards/auth.guard.ts — archivo nuevo creado manualmenteTypeScript
import { Injectable } from '@angular/core';
import { CanActivate, Router } from '@angular/router';
import { AuthService } from '../services/auth.service';

@Injectable({ providedIn: 'root' })
export class AuthGuard implements CanActivate {

  constructor(
    private authService: AuthService,
    private router:      Router
  ) { }

  canActivate(): boolean {
    if (this.authService.isLoggedIn()) {
      return true;  // hay token — puede entrar
    }
    // No hay token — redirigir al login
    this.router.navigate(['/login']);
    return false;
  }
}
Como funciona en la ruta: cuando el usuario intenta ir a /users, Angular llama a AuthGuard.canActivate() antes de cargar el componente. Si devuelve true, carga la pagina. Si devuelve false, redirige a /login.

CartService y BehaviorSubject

Estado compartido del carrito con persistencia por usuario: cada item guarda producto, cantidad y subtotal en localStorage["cart"].

Que es BehaviorSubject

Un BehaviorSubject es un Observable especial que guarda el ultimo valor emitido y lo entrega inmediatamente a cualquier componente que se suscriba:

Codigo que se vuelve dificil de mantener
// Products y App tienen copias separadas
// y hay que sincronizarlas manualmente

// App (navbar):
contadorCarrito = 0;

// Products:
carrito = [];

// Al agregar un producto hay que actualizar
// ambos en cada cambio — codigo fragil
Como mejorar: BehaviorSubject compartido
// Una sola fuente de verdad en CartService
cartItems$ = new BehaviorSubject([]);

// Cualquier componente se suscribe:
cartService.cartItems$.subscribe(items => {
  this.contadorCarrito = items.length;
});
// Se actualiza automaticamente

src/app/services/cart.service.tsTypeScript
import { Injectable } from '@angular/core';
import { BehaviorSubject } from 'rxjs';

interface CartItem {
  userId: number;
  productId: number;
  title: string;
  price: number;
  image: string;
  quantity: number;
  subtotal: number;
}

@Injectable({ providedIn: 'root' })
export class CartService {

  private cartItems = new BehaviorSubject<CartItem[]>([]);
  cartItems$ = this.cartItems.asObservable();

  constructor() {
    this.loadCartForCurrentUser();
  }

  private getCurrentUserId(): number | null {
    const raw = localStorage.getItem('currentUser');
    if (!raw) return null;
    const user = JSON.parse(raw);
    return user.id;
  }

  private getCartMap(): Record<string, CartItem[]> {
    const raw = localStorage.getItem('cart');
    return raw ? JSON.parse(raw) : {};
  }

  private saveCartMap(map: Record<string, CartItem[]>): void {
    localStorage.setItem('cart', JSON.stringify(map));
  }

  loadCartForCurrentUser(): void {
    const userId = this.getCurrentUserId();
    if (!userId) {
      this.cartItems.next([]);
      return;
    }
    const map = this.getCartMap();
    this.cartItems.next(map[userId] || []);
  }

  addToCart(product: any): void {
    const userId = this.getCurrentUserId();
    if (!userId) return;

    const current = [...this.cartItems.getValue()];
    const idx = current.findIndex(i => i.productId === product.id);

    if (idx >= 0) {
      current[idx].quantity += 1;
      current[idx].subtotal = current[idx].price * current[idx].quantity;
    } else {
      current.push({
        userId: userId,
        productId: product.id,
        title: product.title,
        price: product.price,
        image: product.image,
        quantity: 1,
        subtotal: product.price
      });
    }

    this.persistCurrentUserCart(current, userId);
  }

  updateQuantity(productId: number, quantity: number): void {
    const userId = this.getCurrentUserId();
    if (!userId) return;

    const updated = this.cartItems.getValue().map(item => {
      if (item.productId !== productId) return item;
      const qty = Math.max(1, quantity);
      return { ...item, quantity: qty, subtotal: item.price * qty };
    });

    this.persistCurrentUserCart(updated, userId);
  }

  removeFromCart(productId: number): void {
    const userId = this.getCurrentUserId();
    if (!userId) return;

    const updated = this.cartItems.getValue().filter(item => item.productId !== productId);
    this.persistCurrentUserCart(updated, userId);
  }

  clearCart(): void {
    const userId = this.getCurrentUserId();
    if (!userId) return;
    this.persistCurrentUserCart([], userId);
  }

  getTotal(): number {
    return this.cartItems.getValue().reduce((acc, item) => acc + item.subtotal, 0);
  }

  getCount(): number {
    return this.cartItems.getValue().reduce((acc, item) => acc + item.quantity, 0);
  }

  private persistCurrentUserCart(items: CartItem[], userId: number): void {
    const map = this.getCartMap();
    map[userId] = items;
    this.saveCartMap(map);
    this.cartItems.next(items);
  }
}
Formato de localStorage["cart"]: se guarda un objeto por usuario. Ejemplo: { "1": [{ productId: 5, quantity: 2, subtotal: 1390 }], "2": [...] }. Asi, cada alumno puede cerrar sesion e iniciar con otro usuario sin mezclar carritos.

import { Component, OnInit } from '@angular/core';
import { CartService } from '../services/cart.service';
import Swal from 'sweetalert2';  // NUEVO

@Component({
  selector: 'app-cart',
  standalone: false,
  templateUrl: './cart.html',
  styleUrl: './cart.css'
})
export class Cart implements OnInit {
  items: any[] = [];

  constructor(private cartService: CartService) {}

  ngOnInit(): void {
    this.cartService.loadCartForCurrentUser();
    this.cartService.cartItems$.subscribe(r => this.items = r);
  }

  sumar(item: any): void {
    this.cartService.updateQuantity(item.productId, item.quantity + 1);
  }

  restar(item: any): void {
    this.cartService.updateQuantity(item.productId, item.quantity - 1);
  }

  eliminar(item: any): void {                              // NUEVO — modal de confirmacion
    Swal.fire({
      title:              '¿Eliminar producto?',
      text:               `${item.title} será removido del carrito`,
      icon:               'warning',
      showCancelButton:   true,
      confirmButtonColor: '#dc3545',
      cancelButtonColor:  '#6c757d',
      confirmButtonText:  'Sí, eliminar',
      cancelButtonText:   'Cancelar'
    }).then((result) => {
      if (result.isConfirmed) {                            // solo elimina si el usuario confirma
        this.cartService.removeFromCart(item.productId);
        Swal.fire('Eliminado', `${item.title} fue removido del carrito`, 'success');
      }
    });
  }

  total(): number {
    return this.cartService.getTotal();
  }
}

Paso 13 app.ts actualizado

El componente raiz (App) se suscribe al carrito en ngOnInit(). El navbar muestra el contador actualizado y los botones Login/Logout segun el estado de sesion:

src/app/app.ts — version Clase 7TypeScript
import { Component, OnInit } from '@angular/core';
import { Router } from '@angular/router';
import { AuthService } from './services/auth.service';
import { CartService } from './services/cart.service';

@Component({
  selector:    'app-root',
  standalone:  false,
  templateUrl: './app.html',
  styleUrl:    './app.css'
})
export class App implements OnInit {

  contadorCarrito: number = 0;

  constructor(
    public  authService: AuthService,  // public para usarlo directamente en app.html
    private cartService: CartService,
    private router:      Router
  ) { }

  ngOnInit(): void {
    // Suscribirse al carrito — contadorCarrito se actualiza automaticamente
    this.cartService.cartItems$.subscribe(items => {
      this.contadorCarrito = items.length;
    });
  }

  logout(): void {
    this.authService.logout();
    // currentUser ya fue eliminado del localStorage — loadCartForCurrentUser emite [] y el contador vuelve a 0
    this.cartService.loadCartForCurrentUser();  // NUEVO — resetea contador a 0
    this.router.navigate(['/login']);
  }
}
Por que public authService? Para poder llamar a authService.isLoggedIn() directamente en app.html. Las propiedades private no son accesibles desde el template. Solo las propiedades public pueden usarse en el HTML.

Errores comunes y sus soluciones

1 El interceptor no agrega el token

DevTools — Network — las peticiones no tienen el header Authorization
Las peticiones a /users llegan sin token
Verificar que el interceptor esta en providers de app-module.ts: { provide: HTTP_INTERCEPTORS, useClass: AuthInterceptor, multi: true }. Un error comun es agregarlo en imports en lugar de providers.

2 El guard no redirige — entra a /users sin login

app-routing-module.ts
Se puede acceder a /users sin haber hecho login
Verificar que la ruta tiene canActivate: [AuthGuard] y que AuthGuard esta importado en app-routing-module.ts: import { AuthGuard } from './guards/auth.guard'.

3 El contador del carrito siempre muestra 0

app.ts
contadorCarrito siempre muestra 0 aunque se agregan productos
Verificar que en ngOnInit() de app.ts esta la suscripcion: this.cartService.cartItems$.subscribe(items => this.contadorCarrito = items.length). Sin ella, el componente no recibe los cambios del BehaviorSubject.

4 Error: Login is not a known element

Compilacion Angular
'app-login' is not a known element
El componente no esta en declarations de app-module.ts. Si lo generaste con el CLI deberia estar registrado automaticamente. Verificar que el import apunta al archivo correcto: import { Login } from './login/login' (sin sufijo .component).

Preguntas frecuentes

Por que public authService en app.ts?

Para poder llamar a authService.isLoggedIn() desde app.html. Las propiedades private no son accesibles en el template. Solo las public pueden usarse en el HTML.

Diferencia entre Observable y BehaviorSubject?

Un Observable normal solo emite valores cuando hay nuevos datos. Un BehaviorSubject siempre tiene un valor actual y lo entrega inmediatamente a cualquier nuevo suscriptor. Por eso es ideal para el carrito: cuando el navbar se carga, recibe el conteo actual sin esperar.

El token de FakeStoreAPI es seguro para produccion?

No — es una API de prueba para aprendizaje. En produccion el JWT lo genera tu propio backend con una clave secreta real. El flujo es identico: POST login — token — localStorage — interceptor.
