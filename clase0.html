¿Qué es JavaScript?

El lenguaje que le da vida a las páginas web.

La trinidad del Frontend

Toda página web está construida con tres tecnologías que trabajan juntas:

🧱 HTML

Estructura. Define qué elementos existen: títulos, párrafos, botones, imágenes.

<button id="btn">Clic</button>
🎨 CSS

Estilo. Define cómo se ven los elementos: colores, tamaños, posición.

button { color: blue; }
⚡ JavaScript

Comportamiento. Define qué pasa cuando el usuario interactúa.

btn.onclick = () => alert("¡Hola!");
Analogía: HTML es el esqueleto, CSS es la ropa y el maquillaje, JavaScript es los músculos que hacen que el cuerpo se mueva.

¿Cómo se incluye JavaScript en una página?

Hay tres formas. Conocerlas todas te ayuda a entender el código que encuentres en proyectos reales.

① Inline — directamente en el atributo HTML No recomendado

inline.html
<!-- El JS va dentro del atributo del elemento -->
<button onclick="alert('Hola!')">Clic aquí</button>

<!-- Problema: mezcla HTML con JS, difícil de mantener -->

② Etiqueta <script> — dentro del HTML Para aprender/prototipos

script-interno.html
<body>
  <h1>Mi página</h1>

  <!-- El script va al FINAL del body para que el HTML ya esté cargado -->
  <script>
    console.log("¡Hola desde JavaScript!");
    alert("La página cargó");
  </script>
</body>

③ Archivo externo .js — la forma profesional Recomendado

index.html + app.js
<!-- En el HTML, antes de cerrar </body> -->
<script src="app.js"></script>

/* En app.js (archivo separado) */
console.log("Código limpio y separado del HTML");
La consola del navegador es tu mejor amiga para aprender. Abre con F12 → pestaña Console. Puedes escribir JavaScript directamente ahí y ver el resultado inmediato.

Variables y Tipos de Datos

Las variables son cajas donde guardamos información para usarla después.

var, let y const — ¿cuál usar?

JavaScript tiene tres formas de declarar variables. Hoy en día se usan let y const:

variables.js
// const → valor que NO cambia (la mayoría de los casos)
const nombre = "Ana";
const PI     = 3.14159;

// let → valor que SÍ puede cambiar
let edad   = 25;
let activo = true;
edad = 26;  // ✓ Válido con let

// var → la forma antigua, evitarla
var viejo = "no usar";  // Tiene comportamientos confusos

// Regla práctica:
// → Siempre usa const. Si necesitas reasignar, cambia a let.
Regla de oro: Empieza siempre con const. Si en algún momento necesitas cambiar el valor, entonces cambia a let. Nunca uses var en código nuevo.

Tipos de Datos

JavaScript es un lenguaje de tipado dinámico: no declaras el tipo, JS lo infiere solo.

tipos.js
// STRING — texto, siempre entre comillas
const nombre   = "JavaScript";
const saludo   = 'Hola mundo';
const template = `Hola, soy ${nombre}`;  // Template literal

// NUMBER — números enteros y decimales
const entero  = 42;
const decimal = 19.99;
const negativo = -8;

// BOOLEAN — solo true o false
const esMayor = true;
const logueado = false;

// NULL — ausencia intencional de valor
let usuarioActual = null;  // Aún no hay usuario

// UNDEFINED — variable declarada sin valor
let resultado;
console.log(resultado);  // undefined

// OBJECT — colección de propiedades (lo veremos más)
const persona = { nombre: "Luis", edad: 30 };

// ARRAY — lista ordenada (también es un objeto)
const frutas = ["manzana", "pera", "uva"];

// typeof → ver el tipo de cualquier valor
console.log(typeof nombre);   // "string"
console.log(typeof entero);   // "number"
console.log(typeof esMayor);  // "boolean"

Estructuras de Flujo

Controlan qué código se ejecuta y cuántas veces.

if / else — Tomar decisiones

if-else.js
const edad = 20;

if (edad >= 18) {
  console.log("Mayor de edad ✓");
} else if (edad >= 13) {
  console.log("Adolescente");
} else {
  console.log("Menor de edad");
}

// Operadores de comparación
// ==  igualdad de valor (evitar)
// === igualdad de valor Y tipo (usar este siempre)
// !=  diferente valor
// !   negación (NOT)
// &&  Y lógico (AND)
// ||  O lógico (OR)

const usuario = "admin";
const pass    = "1234";

if (usuario === "admin" && pass === "1234") {
  console.log("Bienvenido 🎉");
} else {
  console.log("Credenciales incorrectas ✗");
}

Bucles — Repetir código

bucles.js
// FOR clásico — cuando sabes cuántas veces repetir
for (let i = 0; i < 3; i++) {
  console.log("Vuelta número:", i);
}
// Imprime: 0, 1, 2

// FOR...OF — recorrer arrays (el más usado en la práctica)
const frutas = ["🍎 Manzana", "🍐 Pera", "🍇 Uva"];

for (const fruta of frutas) {
  console.log(fruta);
}

// WHILE — mientras se cumpla la condición
let contador = 0;
while (contador < 3) {
  console.log("Contador:", contador);
  contador++;
}

// forEach — forma funcional de recorrer arrays
frutas.forEach(function(fruta, indice) {
  console.log(indice, fruta);
});
¿Cuál usar? En proyectos modernos con arrays usarás casi siempre forEach o for...of. El for clásico se usa cuando necesitas el índice o hacer algo más complejo.

Funciones

Bloques de código reutilizables. La base de cualquier programa.

Tres formas de declarar funciones

funciones.js
// ① Función declarada — la forma clásica
function saludar(nombre) {
  return `Hola, ${nombre}!`;
}
console.log(saludar("Ana"));  // "Hola, Ana!"

// ② Función expresión — guardada en una variable
const sumar = function(a, b) {
  return a + b;
};
console.log(sumar(3, 7));  // 10

// ③ Arrow function — sintaxis moderna y compacta
const multiplicar = (a, b) => a * b;
console.log(multiplicar(4, 5));  // 20

// Con varias líneas necesita llaves y return explícito
const calcularPrecio = (precio, descuento) => {
  const descuentoAmt = precio * (descuento / 100);
  return precio - descuentoAmt;
};
console.log(calcularPrecio(100, 20));  // 80

Parámetros y valores por defecto

parametros.js
// Parámetro con valor por defecto
function saludar(nombre = "Visitante") {
  return `Bienvenido, ${nombre}!`;
}
console.log(saludar("Carlos")); // "Bienvenido, Carlos!"
console.log(saludar());         // "Bienvenido, Visitante!"

// Función que puede retornar distintos tipos
function dividir(a, b) {
  if (b === 0) {
    return "Error: no se puede dividir entre 0";
  }
  return a / b;
}
console.log(dividir(10, 2));  // 5
console.log(dividir(10, 0));  // "Error: no se puede dividir entre 0"
¿Cuándo usar Arrow Functions? Son perfectas para funciones cortas, callbacks y métodos de arrays como map, filter, forEach. Para funciones principales y métodos de clase, usa la declaración clásica.

Arreglos (Arrays)

Listas ordenadas de elementos. Son fundamentales para manejar datos de APIs.

Crear y acceder a arreglos

arrays-basico.js
// Crear un array
const colores  = ["rojo", "verde", "azul"];
const numeros  = [10, 20, 30, 40];
const mixto    = ["Laptop", 999, true];  // Puede tener tipos distintos

// Acceder por índice (empieza en 0)
console.log(colores[0]);   // "rojo"
console.log(colores[2]);   // "azul"
console.log(colores.length); // 3 — cantidad de elementos

// Modificar un elemento
colores[1] = "amarillo";   // ["rojo", "amarillo", "azul"]

// Agregar y quitar elementos
colores.push("negro");    // agrega al final
colores.pop();            // quita el último
colores.unshift("blanco"); // agrega al inicio
colores.shift();          // quita el primero

Métodos funcionales — los más importantes

Estos métodos son los que más vas a usar cuando recibas datos de una API:

array-metodos.js
const productos = [
  { id: 1, nombre: "Laptop",   precio: 999,  stock: true  },
  { id: 2, nombre: "Mouse",    precio: 29,   stock: false },
  { id: 3, nombre: "Monitor",  precio: 350,  stock: true  },
  { id: 4, nombre: "Teclado",  precio: 45,   stock: true  },
];

// MAP → transforma cada elemento, devuelve nuevo array
const nombres = productos.map(p => p.nombre);
// ["Laptop", "Mouse", "Monitor", "Teclado"]

const conIva = productos.map(p => ({
  ...p,
  precioConIva: (p.precio * 1.13).toFixed(2)
}));

// FILTER → filtra elementos, devuelve nuevo array
const disponibles = productos.filter(p => p.stock === true);
// [Laptop, Monitor, Teclado]

const caros = productos.filter(p => p.precio > 100);
// [Laptop, Monitor]

// FIND → devuelve el PRIMER elemento que cumple la condición
const laptop = productos.find(p => p.id === 1);
// { id:1, nombre:"Laptop", ... }

// SOME → ¿algún elemento cumple la condición? (boolean)
const hayStock = productos.some(p => p.stock);  // true

// EVERY → ¿todos cumplen la condición? (boolean)
const todosConStock = productos.every(p => p.stock); // false
¡Muy importante! Cuando en la Clase 1 recibas un array de productos de la API, usarás exactamente estos métodos: map para renderizar tarjetas, filter para buscar, find para obtener uno por id.

Objetos

Estructuras que agrupan datos relacionados bajo un mismo nombre. Así vienen los datos de las APIs.

Crear y usar objetos

objetos.js
// Un objeto es una colección de pares clave: valor
const producto = {
  id:          1,
  nombre:      "Laptop Pro",
  precio:      1299.99,
  disponible:  true,
  categorias:  ["electrónica", "computadoras"],
  especificaciones: {           // Objeto anidado
    ram:  "16GB",
    disco: "512GB SSD"
  }
};

// Acceder a propiedades — dos formas
console.log(producto.nombre);          // "Laptop Pro" — notación punto
console.log(producto["precio"]);       // 1299.99 — notación corchete
console.log(producto.especificaciones.ram);  // "16GB"

// Modificar y agregar propiedades
producto.precio = 1099.99;          // Modificar
producto.descuento = 15;             // Agregar nueva propiedad

// Verificar si una propiedad existe
console.log("nombre" in producto);   // true
console.log("color"  in producto);   // false

// Obtener todas las claves o valores
console.log(Object.keys(producto));   // ["id", "nombre", "precio"...]
console.log(Object.values(producto)); // [1, "Laptop Pro", 1099.99...]

Desestructuración — forma moderna de extraer datos

destructuring.js
const usuario = {
  nombre: "María",
  email:  "[email protected]",
  edad:   28,
  rol:    "admin"
};

// Sin desestructuración — repetitivo
const nombre = usuario.nombre;
const email  = usuario.email;

// Con desestructuración — limpio y moderno
const { nombre, email, edad } = usuario;
console.log(nombre);  // "María"
console.log(email);   // "[email protected]"

// Muy usado en funciones que reciben objetos
function mostrarUsuario({ nombre, rol }) {
  console.log(`${nombre} es ${rol}`);
}
mostrarUsuario(usuario);  // "María es admin"

// Spread operator — copiar o combinar objetos
const actualizado = { ...usuario, edad: 29 };
// Crea nuevo objeto con todos los datos + edad modificada
¿Para qué sirve esto en la práctica? Cuando recibas un objeto de una API, usarás desestructuración constantemente para extraer solo los campos que necesitas mostrar.

El DOM — Document Object Model

Cómo JavaScript "ve" y puede modificar la página HTML.

¿Qué es el DOM?

Cuando el navegador carga un archivo HTML, lo transforma en un árbol de objetos que JavaScript puede leer y modificar. A ese árbol se le llama DOM.

Piénsalo así: el HTML es el plano de la casa, el DOM es la casa construida que puedes modificar en tiempo real.

▼ <html>
  ▼ <head>
    <title> "Mi Página"
  ▼ <body>
    ▼ <div id="app">
      <h1> "Tienda"
      ▼ <ul id="lista">
        <li> "Producto 1"
        <li> "Producto 2"
    <button id="btn"> "Cargar"

Cada elemento HTML se convierte en un nodo del árbol. JS puede seleccionar, crear, modificar y eliminar cualquier nodo.

Seleccionar elementos del DOM

seleccionar-dom.js
// getElementById — el más directo, por id único
const titulo   = document.getElementById("titulo");
const boton    = document.getElementById("btn-cargar");

// querySelector — selecciona con CSS selector, el primero que encuentre
const parrafo  = document.querySelector("p");
const card     = document.querySelector(".card");
const inputNom = document.querySelector("#nombre");

// querySelectorAll — devuelve TODOS los que coinciden (NodeList)
const tarjetas = document.querySelectorAll(".tarjeta");
const inputs   = document.querySelectorAll("input");

// Recorrer el resultado de querySelectorAll
tarjetas.forEach(function(tarjeta) {
  console.log(tarjeta.textContent);
});

Modificar elementos del DOM

modificar-dom.js
const titulo = document.getElementById("titulo");

// Cambiar texto
titulo.textContent = "Nuevo título";

// Cambiar HTML interno (puede incluir etiquetas)
titulo.innerHTML = "<strong>Título</strong> modificado";

// Cambiar estilos CSS directamente
titulo.style.color      = "red";
titulo.style.fontSize   = "2rem";
titulo.style.display    = "none";   // Ocultar

// Agregar y quitar clases CSS
titulo.classList.add("activo");
titulo.classList.remove("oculto");
titulo.classList.toggle("resaltado");  // Agrega si no tiene, quita si tiene
titulo.classList.contains("activo");   // true/false

// Leer el valor de un input
const input = document.getElementById("busqueda");
console.log(input.value);  // Lo que el usuario escribió

// Agregar HTML nuevo al contenedor
const lista = document.getElementById("lista");
lista.innerHTML += `<li>Nuevo elemento</li>`;

    Modelo de Gestión de Eventos

    Los eventos permiten que tu código responda a las acciones del usuario.

    ¿Qué es un evento?

    Un evento es cualquier cosa que sucede en la página: el usuario hace clic, escribe, mueve el mouse, carga la página, etc. JavaScript puede "escuchar" esos eventos y ejecutar código cuando ocurren.

    La forma correcta de manejar eventos es con addEventListener:

    eventos-basico.js
    // Sintaxis: elemento.addEventListener("evento", función)

const boton = document.getElementById("mi-boton");

// Con función clásica
boton.addEventListener("click", function() {
  console.log("¡El botón fue clickeado!");
});

// Con arrow function (más compacto)
boton.addEventListener("click", () => {
  console.log("También funciona así");
});

// El parámetro "event" tiene info sobre lo que pasó
boton.addEventListener("click", (event) => {
  console.log("Elemento clickeado:", event.target);
  console.log("Tipo de evento:",    event.type);
});

    Los eventos más usados

    ① click — El usuario hace clic

    evento-click.js
    const btn = document.getElementById("btn-guardar");

btn.addEventListener("click", () => {
  const nombre = document.getElementById("input-nombre").value;

  if (nombre === "") {
    alert("El nombre no puede estar vacío");
    return;
  }
  console.log("Guardando:", nombre);
});

    ② input — Mientras el usuario escribe (en tiempo real)

    evento-input.js
    const campo = document.getElementById("busqueda");
const resultado = document.getElementById("resultado");

campo.addEventListener("input", () => {
  // Se ejecuta con CADA tecla que el usuario presiona
  const texto = campo.value;
  resultado.textContent = `Buscando: "${texto}"`;

  // Ideal para búsqueda en tiempo real
  const filtrados = productos.filter(p =>
    p.nombre.toLowerCase().includes(texto.toLowerCase())
  );
});

    ③ keyup — Cuando se suelta una tecla

    evento-keyup.js
    const input = document.getElementById("mi-input");

input.addEventListener("keyup", (event) => {
  // Detectar tecla específica
  if (event.key === "Enter") {
    console.log("Enter presionado, buscando...");
    buscar(input.value);
  }
  if (event.key === "Escape") {
    input.value = "";  // Limpiar con Escape
  }
});

    ④ change — Cuando cambia el valor (al salir del campo)

    evento-change.js

    localStorage

    Guardar datos en el navegador del usuario de forma permanente (hasta que se borren).

    ¿Qué es localStorage?

    localStorage es un espacio de almacenamiento en el navegador. Funciona como una mini base de datos de pares clave → valor. Los datos persisten aunque cierres y vuelvas a abrir el navegador.

    setItem()
    Guardar
    getItem()
    Leer
    removeItem()
    Eliminar

    Guardar y leer datos

    Importante: localStorage solo guarda strings (texto). Para guardar objetos o arrays hay que convertirlos a JSON.

    localstorage-tipos.js
    // ── STRINGS ──────────────────────────────
localStorage.setItem("nombre", "Carlos");
const nombre = localStorage.getItem("nombre");
console.log(nombre);  // "Carlos"

// ── NÚMEROS ──────────────────────────────
// Se guardan como string, hay que convertirlos al leer
localStorage.setItem("edad", 25);
const edadStr = localStorage.getItem("edad");
console.log(typeof edadStr);           // "string" ← ojo!
const edadNum = Number(edadStr);        // Convertir de vuelta a número
console.log(typeof edadNum);           // "number" ✓

// ── OBJETOS / JSON ───────────────────────
const usuario = { id: 1, nombre: "Ana", rol: "admin" };

// Guardar: convertir objeto → string JSON
localStorage.setItem("usuario", JSON.stringify(usuario));

// Leer: convertir string JSON → objeto
const guardado  = localStorage.getItem("usuario");
const usuarioObj = JSON.parse(guardado);
console.log(usuarioObj.nombre);  // "Ana"
console.log(usuarioObj.rol);     // "admin"

// ── ARRAYS ───────────────────────────────
const carrito = [
  { id: 1, producto: "Laptop", cantidad: 1 },
  { id: 2, producto: "Mouse",  cantidad: 2 }
];
localStorage.setItem("carrito", JSON.stringify(carrito));

const carritoGuardado = JSON.parse(localStorage.getItem("carrito"));
console.log(carritoGuardado[0].producto);  // "Laptop"

// ── ELIMINAR ────────────────────────────
localStorage.removeItem("nombre");  // Borra una clave
localStorage.clear();              // Borra todo (¡cuidado!)
    Patrón seguro para leer: Siempre verifica que el dato existe antes de parsear, porque getItem devuelve null si la clave no existe, y JSON.parse(null) da error.
    patron-seguro.js
    // ✓ Forma segura de leer un objeto/array
function leerDelStorage(clave) {
  const dato = localStorage.getItem(clave);
  return dato ? JSON.parse(dato) : null;
}

const carrito = leerDelStorage("carrito") || [];
// Si no existe, usa array vacío como valor por defecto

    // ① EVENTO: esperar el clic del botón
const boton = document.getElementById("btn-cargar");   // DOM ✓

boton.addEventListener("click", async function() {   // Evento + función async ✓

  // ② FETCH: pedir datos a la API
  const response = await fetch("https://fakestoreapi.com/products");
  const productos  = await response.json();  // Devuelve un array de objetos ✓

  // ③ ARRAY: recorrer los productos
  const contenedor = document.getElementById("contenedor");  // DOM ✓
  contenedor.innerHTML = "";  // Limpiar antes de renderizar

  productos.forEach(function(producto) {                   // forEach ✓
    // ④ OBJETO: acceder a propiedades del producto
    const { title, price, image } = producto;              // Desestructuración ✓

    // ⑤ DOM: insertar tarjeta en la página
    contenedor.innerHTML += `                              // Template literal ✓
      <div class="tarjeta">
        <img src="${image}">
        <h3>${title}</h3>
        <p>$${price.toFixed(2)}</p>    // Número ✓
      </div>
    `;
  });

  // ⑥ localStorage: guardar para no volver a pedir
  localStorage.setItem("productos", JSON.stringify(productos)); // localStorage ✓
});
