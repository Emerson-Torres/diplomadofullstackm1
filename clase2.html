Promesas & async/await

El modelo mental para entender por qué el código con APIs se escribe diferente.

¿Por qué existe la asincronía?

JavaScript es single-threaded: ejecuta una sola instrucción a la vez. Si tuviera que esperar a que cada petición a una API respondiera antes de continuar, la página se congelaría.

La solución: lanzar la petición y continuar. Cuando llegue la respuesta, ejecutar el código correspondiente. Esto es la asincronía.

Analogía: Pides una pizza por teléfono (fetch) y mientras esperas sigues viendo la TV (el resto del código). Cuando llega el delivery (respuesta), pausas la TV y recibes la pizza (.then / await).

¿Qué es una Promesa?

Una Promesa (Promise) es un objeto que representa el resultado eventual de una operación asíncrona. Tiene tres estados posibles:

⏳ pending
→
✓ fulfilled (resuelta)
o
✗ rejected (rechazada)
promesa-basica.js
// fetch() devuelve una Promesa
const promesa = fetch("https://fakestoreapi.com/products/1");

console.log(promesa);
// Promise { <pending> }  ← todavía no llegó la respuesta

// .then() se ejecuta cuando la promesa se RESUELVE
// .catch() se ejecuta si la promesa es RECHAZADA
promesa
  .then(response => response.json())
  .then(data => console.log(data.title))
  .catch(error => console.error("Falló:", error));

.then() vs async/await — comparativa

Ambas formas hacen exactamente lo mismo. async/await es syntactic sugar sobre Promesas — el navegador lo convierte internamente a .then().

Con .then() — Encadenado
fetch("...url...")
  .then(res => res.json())
  .then(data => {
    // usar data
    mostrar(data);
  })
  .catch(err => {
    console.error(err);
  });
Con async/await — Lineal ✓
async function cargar() {
  try {
    const res  = await fetch("...url...");
    const data = await res.json();
    // usar data
    mostrar(data);
  } catch(err) {
    console.error(err);
  }
}
¿Cuál usar? async/await siempre que puedas. El código se lee de arriba a abajo como si fuera síncrono, es más fácil de depurar y el manejo de errores con try/catch es más limpio. .then() lo verás en código viejo y en la Clase 3 con jQuery.

Errores comunes con async/await

errores-comunes.js
// ✗ ERROR 1: usar await fuera de una función async
const data = await fetch("..."); // SyntaxError!

// ✓ CORRECTO: siempre dentro de async function
async function cargar() {
  const data = await fetch("..."); // ✓
}

// ✗ ERROR 2: olvidar el segundo await para .json()
async function mal() {
  const res  = await fetch("...");
  const data = res.json(); // ← falta await! data es una Promesa, no el objeto
  console.log(data.title); // undefined
}

// ✓ CORRECTO
async function bien() {
  const res  = await fetch("...");
  const data = await res.json(); // ✓ dos awaits
  console.log(data.title);
}

// ✗ ERROR 3: no manejar el error de red
async function sinManejo() {
  const res = await fetch("url-que-no-existe");
  // Si falla la red → Uncaught (in promise) TypeError
}

// ✓ CORRECTO: siempre try/catch
async function conManejo() {
  try {
    const res  = await fetch("...");
    const data = await res.json();
    mostrar(data);
  } catch (error) {
    mostrarError("No se pudo cargar. Intenta de nuevo.");
  }
}

Eventos del DOM — El puente entre el usuario y la API

Cómo reaccionar a las acciones del usuario para disparar peticiones.

El patrón fundamental

Toda aplicación web moderna sigue este patrón: evento del usuario → petición a la API → actualizar el DOM.

1
Usuario hace clic / escribe / selecciona
2
addEventListener captura el evento
3
fetch() pide datos a la API
4
DOM se actualiza con la respuesta
patron-fundamental.js
// El patrón completo en su forma más simple
const btn = document.getElementById("btn-cargar");

btn.addEventListener("click", async function() {

  // 1. Feedback visual inmediato
  btn.textContent = "Cargando...";
  btn.disabled = true;

  try {
    // 2. Petición a la API
    const res      = await fetch("https://fakestoreapi.com/products?limit=4");
    const productos = await res.json();

    // 3. Actualizar el DOM
    const contenedor = document.getElementById("contenedor");
    contenedor.innerHTML = productos.map(p => `
      <div class="tarjeta">
        <img src="${p.image}">
        <h3>${p.title.substring(0,30)}...</h3>
        <p>$${p.price.toFixed(2)}</p>
      </div>
    `).join("");

  } catch(error) {
    console.error("Error:", error);
  } finally {
    // 4. Restaurar el botón siempre (con o sin error)
    btn.textContent = "Cargar productos";
    btn.disabled = false;
  }
});
finally se ejecuta siempre, haya error o no. Es el lugar ideal para restaurar el estado del botón, ocultar spinners o limpiar recursos.

Eventos útiles para filtrar productos

// Búsqueda en tiempo real con "input"
const inputBusqueda = document.getElementById("busqueda");

inputBusqueda.addEventListener("input", function() {
  const texto = this.value.toLowerCase();

  // Filtrar tarjetas ya renderizadas en el DOM

// Filtro por categoría con "change"

fetch() + DOM — El patrón completo

Conectar una petición real con la interfaz visual, incluyendo estados de carga y errores.

Los tres estados de una carga

Cualquier operación asíncrona tiene tres estados que debes manejar en la UI:

⏳ Loading

Mostrar un spinner o skeleton. Deshabilitar el botón. El usuario sabe que algo está pasando.

✓ Success

Ocultar el spinner, renderizar los datos. El usuario ve el resultado.

✗ Error

Mostrar mensaje claro. Ofrecer reintentar. Nunca dejar la UI congelada.

Implementación con los tres estados

fetch-con-estados.js
async function cargarProductos() {
  const contenedor = document.getElementById("productos");

  // ── ESTADO: LOADING ──────────────────────
  contenedor.innerHTML = `
    <div class="text-center py-4">
      <div class="spinner-border text-success"></div>
      <p class="mt-2 text-muted">Cargando productos...</p>
    </div>
  `;

  try {
    const res       = await fetch("https://fakestoreapi.com/products?limit=6");

    // Verificar que la respuesta HTTP fue exitosa
    if (!res.ok) throw new Error(`HTTP Error: ${res.status}`);

    const productos  = await res.json();

    // ── ESTADO: SUCCESS ───────────────────────
    contenedor.innerHTML = productos.map(p => `
      <div class="col">
        <div class="product-card">
          <img src="${p.image}" alt="${p.title}">
          <div class="p-title">${p.title.substring(0,40)}...</div>
          <div class="p-price">$${p.price.toFixed(2)}</div>
        </div>
      </div>
    `).join("");

  } catch(error) {
    // ── ESTADO: ERROR ─────────────────────────
    contenedor.innerHTML = `
      <div class="alert alert-danger">
        <strong>Error:</strong> ${error.message}
        <button onclick="cargarProductos()">🔄 Reintentar</button>
      </div>
    `;
  }
}

Tarjetas Dinámicas desde la API

Construir una galería de productos completa con datos reales.

De JSON a HTML — el proceso

Cuando llega el array de productos de la API, hay que transformar cada objeto en un bloque de HTML. El método map() + template literals es la forma idiomática de hacerlo:

json-a-html.js
// La API devuelve esto:
const producto = {
  id: 1,
  title: "Fjallraven Backpack",
  price: 109.95,
  image: "https://fakestoreapi.com/img/81fAn...",
  category: "men's clothing",
  rating: { rate: 3.9, count: 120 }
};

// Y queremos generar esto:
// <div class="product-card">
//   <img src="...">
//   <div class="p-title">Fjallraven...</div>
//   <div class="p-price">$109.95</div>
//   <button class="btn-like" data-id="1">❤️ Me gusta</button>
// </div>

// La función que convierte UN producto en HTML
function crearTarjeta(producto) {
  return `
    <div class="product-card" data-id="${producto.id}">
      <img src="${producto.image}" alt="${producto.title}" loading="lazy">
      <div class="p-title">${producto.title.substring(0, 45)}...</div>
      <div class="p-price">$${producto.price.toFixed(2)}</div>
      <div class="small text-muted">⭐ ${producto.rating.rate} (${producto.rating.count})</div>
      <button class="btn-like" data-id="${producto.id}">🤍 Me gusta</button>
    </div>
  `;
}

// Renderizar TODOS los productos de una vez
async function renderProductos() {
  const res       = await fetch("https://fakestoreapi.com/products?limit=6");
  const productos  = await res.json();
  const contenedor = document.getElementById("galeria");

  // map() convierte cada objeto en HTML, join("") los une en un string
  contenedor.innerHTML = productos.map(crearTarjeta).join("");
}
data-id: El atributo data-* en HTML permite guardar información extra en un elemento. Aquí guardamos el id del producto en el botón para saber qué producto "gustó" cuando el usuario hace clic. Se accede con element.dataset.id.

Estrellas dinámicas con el rating

rating-estrellas.js
// Convertir rating numérico en estrellas visuales
function renderStars(rate) {
  const llenas  = Math.floor(rate);         // estrellas completas
  const media   = rate % 1 >= 0.5 ? 1 : 0; // media estrella
  const vacias  = 5 - llenas - media;

  return "★".repeat(llenas) +
         (media ? "½" : "") +
         "☆".repeat(vacias);
}

console.log(renderStars(3.9)); // "★★★★☆"
console.log(renderStars(4.5)); // "★★★★½"

Favoritos con localStorage

Guardar el estado de "me gusta" de cada producto de forma persistente.

La lógica de favoritos

Al hacer clic en ❤️ necesitamos:

1
Saber qué producto se clickeó (data-id)
2
Leer favoritos actuales del localStorage
3
Agregar o quitar el id según si ya estaba
4
Guardar el array actualizado
5
Actualizar la UI del botón
logica-favoritos.js
// ── Helpers de localStorage ──────────────────
function getFavoritos() {
  const raw = localStorage.getItem("favoritos");
  return raw ? JSON.parse(raw) : [];
}

function saveFavoritos(arr) {
  localStorage.setItem("favoritos", JSON.stringify(arr));
}

// ── Toggle favorito ──────────────────────────
function toggleFavorito(productoId) {
  const favs   = getFavoritos();
  const index  = favs.indexOf(productoId);

  if (index === -1) {
    favs.push(productoId);           // No estaba → agregar
    console.log("❤️ Agregado a favoritos");
  } else {
    favs.splice(index, 1);           // Ya estaba → quitar
    console.log("🤍 Quitado de favoritos");
  }

  saveFavoritos(favs);
  return favs.includes(productoId); // true si quedó en favoritos
}

// ── Escuchar clics en los botones ────────────
// Delegación de eventos: un solo listener en el contenedor
document.getElementById("galeria").addEventListener("click", function(event) {
  const btn = event.target.closest(".btn-like");
  if (!btn) return; // no era el botón de like

  const id      = Number(btn.dataset.id);
  const esLiked = toggleFavorito(id);

  // Actualizar UI del botón
  btn.textContent = esLiked ? "❤️ Me gusta" : "🤍 Me gusta";
  btn.classList.toggle("liked", esLiked);
});
Delegación de eventos: En lugar de poner un addEventListener en cada botón (que pueden ser 20), ponemos uno solo en el contenedor padre. Cuando el usuario hace clic, el evento "burbujea" hasta el contenedor y ahí verificamos si el clic fue en un .btn-like con closest().

Recuperar favoritos al cargar la página

Al renderizar las tarjetas, consultamos el localStorage para marcar las que ya eran favoritas:

recuperar-favoritos.js
function crearTarjeta(producto) {
  const favs    = getFavoritos();
  const esLiked = favs.includes(producto.id);

  // El botón ya arranca con el estado correcto
  return `
    <div class="product-card" data-id="${producto.id}">
      <img src="${producto.image}" loading="lazy">
      <div class="p-title">${producto.title.substring(0,40)}...</div>
      <div class="p-price">$${producto.price.toFixed(2)}</div>
      <button
        class="btn-like ${esLiked ? "liked" : ""}"
        data-id="${producto.id}">
        ${esLiked ? "❤️" : "🤍"} Me gusta
      </button>
    </div>
  `;
}

// Llamar al cargar la página
renderProductos();  // las tarjetas ya saben qué estaba en favoritos

Código completo del ejercicio

tienda.html — código completo
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi Tienda</title>
  <style>
    body { font-family: sans-serif; max-width: 1000px; margin: 0 auto; padding: 20px; }
    .galeria { display: grid; grid-template-columns: repeat(auto-fill, minmax(160px,1fr)); gap:16px; }
    .tarjeta { border:1px solid #ddd; border-radius:8px; padding:12px; text-align:center; }
    .tarjeta img { width:100%; height:120px; object-fit:contain; }
    .tarjeta h3 { font-size:13px; margin:8px 0 4px; }
    .precio     { color:#10b981; font-weight:bold; }
    .btn-like   { width:100%; margin-top:8px; padding:4px; border:1px solid #ddd;
                   border-radius:6px; cursor:pointer; background:white; }
    .btn-like.liked { background:#fef2f2; border-color:#f87171; }
  </style>
</head>
<body>
  <h1>🛍️ Mi Tienda</h1>
  <button id="btn-cargar">Cargar productos</button>
  <p>Favoritos: <span id="contador">0</span></p>
  <div id="galeria" class="galeria"></div>

  <script>
    // ── localStorage helpers ──
    function getFavs() {
      return JSON.parse(localStorage.getItem("favs")) || [];
    }
    function saveFavs(arr) {
      localStorage.setItem("favs", JSON.stringify(arr));
    }
    function actualizarContador() {
      document.getElementById("contador").textContent = getFavs().length;
    }

    // ── Render ──
    function crearTarjeta(p) {
      const liked = getFavs().includes(p.id);
      return `
        <div class="tarjeta">
          <img src="${p.image}" loading="lazy">
          <h3>${p.title.substring(0,35)}...</h3>
          <p class="precio">$${p.price.toFixed(2)}</p>
          <button class="btn-like ${liked?"liked":""}" data-id="${p.id}">
            ${liked?"❤️":"🤍"} Me gusta
          </button>
        </div>
      `;

    // ── Cargar productos ──
    async function cargarProductos() {
      const btn     = document.getElementById("btn-cargar");
      const galeria = document.getElementById("galeria");

      btn.textContent = "⏳ Cargando...";
      btn.disabled = true;

      try {
        const res  = await fetch("https://fakestoreapi.com/products?limit=8");
        const data = await res.json();
        galeria.innerHTML = data.map(crearTarjeta).join("");
        actualizarContador();
      } catch(e) {
        galeria.innerHTML = `<p style="color:red">Error: ${e.message}</p>`;
      } finally {
        btn.textContent = "Cargar productos";
        btn.disabled = false;
      }

    // ── Evento del botón de cargar ──
    document.getElementById("btn-cargar")
      .addEventListener("click", cargarProductos);

    // ── Delegación de eventos para los "Me gusta" ──
    document.getElementById("galeria")
      .addEventListener("click", function(e) {
        const btn = e.target.closest(".btn-like");
        if (!btn) return;

        const id   = Number(btn.dataset.id);
        const favs = getFavs();
        const idx  = favs.indexOf(id);

        if (idx === -1) { favs.push(id); }
        else            { favs.splice(idx, 1); }

        saveFavs(favs);
        const liked = favs.includes(id);
        btn.textContent = (liked ? "❤️" : "🤍") + " Me gusta";
        btn.classList.toggle("liked", liked);
        actualizarContador();
      });

    // ── Cargar al iniciar ──
    cargarProductos();
  </script>
</body>
</html>

  • JSON.parse/stringify — leer y escribir arrays en localStorage
