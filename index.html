Modulo 1 — Angular

Evaluaciones Finales

Hay dos modalidades de evaluación. Elegís una sola para entregar. Ambas construyen una aplicación Angular completa que consume una API real de DummyJSON.

Plazo: 1 semana Fecha límite: martes 12 de mayo 2026 Máx. 2 integrantes por equipo
Nivel Estándar
Evaluación Ideal

Catálogo de productos con Angular y DummyJSON. Navegación, detalle de producto, filtrado por categoría y comparador de hasta 3 ítems persistido en localStorage. Sin autenticación ni guards.

API base: https://dummyjson.com/products
  • Rutas: /products, /product/:id, /comparar
  • Listado con filtro por categoría (dropdown)
  • Detalle con precio original tachado y precio con descuento (price * (1 - discountPercentage/100))
  • Reseñas del producto visibles en el detalle
  • ComparadorService: máx. 3 productos, persistido en localStorage
  • Botón en tarjeta con 3 estados: Comparar / Quitar / Lleno (deshabilitado)
  • Contador en navbar: Comparar (N/3)
  • Vista /comparar con tabla comparativa lado a lado
Nota: aprobar esta evaluación otorga la nota de aprobación del Módulo 1.
Ver consigna completa
Nivel Avanzado
Evaluación Difícil

Recetario (mi-recetario) con autenticación JWT real, guards de ruta, favoritos por usuario con BehaviorSubject y persistencia por userId en localStorage.

APIs: https://dummyjson.com/recipes + /auth/login
  • Rutas: /login, /recipes, /recipe/:id, /favoritos (guard), /perfil (guard)
  • Login real con DummyJSON — respuesta incluye token + datos de usuario
  • Guardar currentUser y token en localStorage
  • AuthGuard que redirige a /login si no hay sesión
  • FavoritosService con BehaviorSubject: loadFavoritosForCurrentUser, esFavorito, toggleFavorito, clearInMemory
  • Botón de favorito en tarjeta solo visible con sesión activa
  • Logout limpia localStorage y resetea el BehaviorSubject
Bonus: nota del Módulo 1 + 3 puntos para el Módulo 2, siempre que la nota sea mayor a 8.

Aclaraciones generales

Plazo y modalidad
  • Se dispone de una semana para realizar la evaluación.
  • Fecha límite: martes 12 de mayo de 2026.
  • Se elige una sola evaluación para entregar: la ideal o la difícil.
Equipos
  • El desarrollo se realiza en parejas como máximo.
  • Si se entrega con más integrantes se descontarán 2 puntos de la nota final.
Calificación
  • Evaluación ideal: aprueba el Módulo 1.
  • Evaluación difícil: aprueba el Módulo 1 y suma +3 puntos al Módulo 2, siempre que la nota sea mayor a 8.
Uso de IA
  • No se restringe el uso de IA.
  • Se valorará el conocimiento técnico aplicado en cada proyecto.
Material de apoyo

Todo lo necesario para realizar la prueba se encuentra en el material visto durante el Módulo 1 (Clases 0 a 7). Usá el índice lateral para repasar cualquier tema.

Entrega
  • El proyecto debe subirse a un repositorio de GitHub.
  • El enlace debe enviarse al Aula Digital mediante un PDF con portada y nombres de los integrantes.
